# Manufacturing Dashboard (Power BI)

## 📊 Project Overview

This project is an "Enterprise Manufacturing Analytics Dashboard" built using "Power BI" to monitor production performance, operational efficiency, and cost analysis.

The dashboard helps stakeholders track key manufacturing KPIs such as:

* Overall Equipment Effectiveness (OEE)
* Production Performance
* Quality Analysis
* Downtime Monitoring
* Cost & Loss Analysis



## 🎯 Business Problem

Manufacturing data was spread across multiple sheets and lacked real-time visibility.
This dashboard provides a "single source of truth" for tracking efficiency, identifying losses, and improving decision-making.



## 🧰 Tools & Technologies Used

* Power BI
* Power Query (ETL)
* DAX Measures
* SQL (Data preparation)
* Excel (Source data)



## 📈 Key KPIs Implemented

* OEE %
* Availability %
* Performance %
* Quality %
* Scrap Amount
* Rework Hours
* Non-Value Added (NVA) Hours
* Consumable Cost



## ⚙️ Features

* Dynamic KPI calculations using DAX
* Interactive slicers and filters
* Drill-down analysis
* Automated OEE calculations
* Department-wise performance tracking
